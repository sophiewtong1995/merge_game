# 糖果玩具大作战

一个使用 Python 和 Pygame 制作的糖果玩具箱风格合成打怪小游戏原型。

## 运行方法

建议使用 Python 3.10 或更高版本：

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python game.py
```

游戏循环同时兼容桌面 asyncio 和 Pygbag 的浏览器事件循环。

## 构建 itch.io 网页版

安装包含固定版本 Pygbag 的开发依赖：

```bash
python -m pip install -r requirements-dev.txt
```

生成 itch.io 可上传的 ZIP：

```bash
./scripts/build_web.sh
```

构建结果位于 `dist/candy-monster-merge-web.zip`。脚本使用发布白名单，并在
暂存目录中将高清 PNG 缩小为适合浏览器的运行尺寸；源素材不会被修改。概念图、
测试文件、预览图和本地虚拟环境都不会进入游戏包。ZIP 根目录包含 itch.io
HTML5 项目所需的 `index.html`。

本地预览必须使用 Pygbag 自带服务器，因为它还会代理并缓存浏览器版 Python
和 Pygame 依赖。完成构建后运行：

```bash
./scripts/serve_web.sh
```

然后打开 `http://localhost:8000`。不要使用 `python -m http.server`，否则浏览器
首次加载 Pygame 依赖时会得到 404，并停留在纯蓝色画布。

如果虚拟环境不在 `.venv`，可以显式指定 Python：

```bash
PYTHON_BIN=/path/to/python ./scripts/build_web.sh
```

## 玩法

- 只能通过拖拽操作合成物品。
- 相同物品可以拖拽到任意距离的位置合成，合成物保留在目标格。
- 拖到空格、不同物品或棋盘外时，原物品返回原位。
- 移动后，相邻且颜色、等级相同的物品也会自动合成。
- 横向合成后保留左边的格子；纵向合成后保留下边的格子。
- 自动合成会预演相邻路径，优先选择能连续合成到最高等级的路线。
- 多条路线能达到相同等级时，按下、左、右、上的顺序决定。
- 连锁合成会让刚生成的物品继续移动到下一个匹配物品的位置。
- 合成可以连续触发，空格补充的新物品只会是一级或二级。
- 最高等级为六级；五级是可继续合成的中间等级，两个五级物品会合成六级物品。
- 每次合成都攻击相同颜色的怪物：一级至五级合成分别造成 1、2、4、8、16 点伤害。
- 单击六级物品后，它会消失并对对应颜色的存活怪物造成 20 点伤害。
- 游戏包含八关；前六关的波次数逐步增加，之后保持每关六波以控制单局长度。
- 普通波需要击败红、蓝、绿三只怪物；Boss 波只有一只高生命 Boss。
- Boss 可以受到红、蓝、绿所有颜色的伤害。
- 第一关没有 Boss；第二、三关各有一只 Boss；第四、五关各有两只 Boss；第六至八关各有三只 Boss。
- 本波清除后会先结算完当前连锁；剩余连锁伤害不会带入下一波。
- 对应颜色的怪物已经被击败时，六级物品仍可点击释放并触发补棋，但不会转移伤害。
- 每关共享有限拖拽次数：八关分别为 24、42、60、82、102、124、140、156 次。
- 进入下一波时保留棋盘和剩余拖拽次数；只有进入新关卡才补满次数。
- 第一至第七关结束后会播放糖果礼花庆祝动画；点击 `CONTINUE` 后进入下一关。
- 只有成功的手动拖拽合成扣除次数；自动连锁、错误拖拽和点击六级物品不扣次数。
- 次数用完且无法再使用六级物品时，如果本波怪物尚未击败，游戏失败。
- 失败后可以恢复进入本关时的棋盘与分数，从本关第一波重新挑战；也可以从第一关开始新游戏。
- 手动拖拽松手后直接显示合成结果；系统触发的自动合成才播放物品移动动画。
- 空格出现后，原有棋子会向下滑落，新棋子从棋盘上方落入并轻微回弹。
- 掉落画面限制在棋盘内部；同列多个新棋子从下到上依次进入，不遮挡怪物区域。
- 合成与掉落采用紧凑动画时长，在保持轨迹清晰的同时减少操作等待。
- 一条连续合成结束后会汇总伤害，从最终物品位置向对应怪物发射炮弹。
- 两条互不连接的合成链会分别发射炮弹，即使它们颜色相同也不会合并伤害。
- 单击六级物品时也会立即发射炮弹，命中后显示伤害与冲击波。
- 合成过程中只累计攻击力；炮弹发射时才一次性扣除怪物生命。
- 单步合成不再显示攻击浮字；炮弹命中后的总伤害会延长显示时间。
- 命中效果保留显示时不会阻塞后续掉落、自动合成或玩家操作。
- 后续关卡与波次中的怪物会获得更多生命值。
- 击败第八关最终 Boss 后完成当前版本的全部关卡。
- 棋盘中的空格会自动下落并随机补充新物品。
- 失败后按 `R` 重试本关，按 `Shift+R` 从第一关开始；游戏进行中需要再次按下相同快捷键确认，按 `Esc` 退出。

## 测试

核心规则不依赖 Pygame，可直接运行：

```bash
python3 -m unittest -v
```

## 语言与字体

- itch.io 发布版本默认使用英文界面；所有界面文案集中在 `localization.py`。
- 中文文案保留在同一语言表中，后续可以在不复制游戏代码的情况下增加语言切换。
- 标题与重点数字使用 Fredoka，普通界面文字使用 Nunito。
- 字体文件随游戏放在 `assets/fonts` 中，授权文件为同目录下的 `OFL-Fredoka.txt` 和 `OFL-Nunito.txt`。
